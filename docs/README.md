# Documentation

This directory contains project documentation, architecture diagrams, and decision records.

## Structure

```
docs/
├── architecture/      # System architecture and design docs
└── adr/              # Architecture Decision Records
```

## Guidelines

- Keep documentation close to the code
- Use markdown for all documentation
- Include diagrams where appropriate
- Update docs when making significant changes
- Follow ADR template for architectural decisions

## Documentation Types

- **Architecture**: High-level system design, component diagrams, data flows
- **ADR**: Record of architectural decisions with context and consequences
