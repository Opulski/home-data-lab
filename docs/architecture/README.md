# Architecture Documentation

This directory contains system architecture documentation and design diagrams.

## Contents

- System overview and architecture
- Component diagrams
- Data flow diagrams
- Infrastructure architecture
- Network topology
- Security architecture

## Guidelines

- Use diagrams to illustrate complex concepts
- Keep documentation up-to-date with code changes
- Include both high-level and detailed views
- Document integration points and APIs
- Explain design rationale

## Diagram Tools

Recommended tools for creating diagrams:
- Mermaid (markdown-native diagrams)
- Draw.io / Diagrams.net
- PlantUML
- Excalidraw
